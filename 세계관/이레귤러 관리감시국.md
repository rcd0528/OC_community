## 2. 위치와 역할

관리감시국은 [[PARAGON]]이나 [[LIMEN]]과 같은 플레이어블 진영이 아니다.

도시의 **법, 기록, 출입 통제, 현장 봉쇄, 사후 브리핑**으로 작동하는 환경 장치다. 러너는 관리감시국에 가입하거나 관리감시국과 직접 전투하지 않는다. 대신 관리감시국이 만든 규칙 안에서 **무엇을 지키고 무엇을 어길지 선택**한다.

환경 장치로 두는 이유는 실용적이다. 관리감시국을 제3진영으로 열면 운영량이 급격히 늘어나지만, 환경 장치로 두면 모든 이벤트에 압력을 줄 수 있다.

---

## 3. 러너가 체감하는 장치들

관리감시국은 다음과 같은 장치로 러너의 행동에 영향을 준다.

| 장치 | 러너가 체감하는 방식 |
| --- | --- |
| 긴급명령 | 특정 구역에서 능력 사용 제한, 출동 명령, 대피 명령 |
| 출입 통제 | 허가증 요구, 제한 구역 진입 시 [[감시도와 여론 시스템\|감시도]] 상승 |
| 감시 로그 | 능력 사용, 폭주, 시민 피해, 로그 조작 기록 |
| 사후 보고 | 전투 후 사건 책임과 공적을 공식 발표 |
| 언론 브리핑 | 시민 여론을 특정 방향으로 유도 |
| 현장 봉쇄 | 이동 경로 제한, 우회 루트 요구 |
| 등록증 알림 | 개인 단위 경고, 소명 요청, 조사 통보 |
| 사법 리스크 | 체포, 소환, 면허 정지, 임무 제한의 근거 |

## 4. 전투 이벤트에서의 등장 방식

관리감시국은 전투 이벤트에서 직접 보스로 나오지 않는다. 대신 이벤트의 각 페이즈에서 압력을 가하는 방식으로 등장한다.

| 시점 | 장치 | 효과 |
| --- | --- | --- |
| 이벤트 시작 | 긴급 봉쇄령 | 구역 이동 제한, 우회 루트 필요 |
| 1페이즈 | 능력 사용 제한 | 고등급 능력 사용 시 감시도 상승 |
| 2페이즈 | 자동 로그 업로드 | 일정 턴 후 현장 기록이 서버로 전송 |
| 3페이즈 | 진압 드론 투입 | 시민 피해가 커지면 양 진영 모두 방해 |
| 종료 후 | 공식 브리핑 | [[감시도와 여론 시스템\|여론]], 감시도, 도시 안정도 변동 |

## 5. 법적 근거 — [[이레귤러 안전 관리법]]

관리감시국의 모든 권한은 USNA [[이레귤러 안전 관리법]]에 근거한다. [[천변과 대격변|스카이룸 결전]] 이후 정권 교체가 있었고, 현 행정부는 안전 우선주의와 감시 강화를 내세운다.

### 안전 관리법 6조항 요약

| 조항 | 내용 |
| --- | --- |
| 1조. 등록 의무 | 18세 또는 능력 발현 시 등록 의무. 미등록은 형사 처벌. |
| 2조. 면허 조항 | 공명지수 측정, 등급별 면허 발급, 정지·취소 절차. |
| 3조. 거주·이동 제한 | A·S등급 대상 거주 신고와 제한 구역 출입 통제. |
| 4조. 고용 우선 | 정부·[[PARAGON]]·인가 기업이 등록 이레귤러를 우선 고용. |
| 5조. 응급 동원 | 재난·폭주 시 등록 이레귤러에게 의무 응답 명령 가능. |
| 6조. 정보 통제 | 사건 보도 승인제, 감시 로그 유출 처벌, 폭주 명단·미등록자 신원 비공개. |

이 법은 러너 캐릭터 설정에 바로 활용할 수 있다. 예를 들어 면허 정지 전력, 응급 동원 거부, 제한 구역 거주, 미등록 상태, [[PARAGON]] 보증인 설정 등이 가능하다. **상세 조항·시행 효과·러너 활용·시민 권리 단체 반대 입장**은 [[이레귤러 안전 관리법]] 문서 참조.

## 6. 정치 배경

스카이룸 결전 이후 5년 사이에 정권 교체가 있었다. 현 행정부는 안전 우선주의를 내세우며 관리감시국의 권한을 강화했다. 이 변화는 두 진영에 각각 다른 영향을 준다.

- [[PARAGON]] 내부 청산파에게는 **개혁의 동기**가 된다 — 정부와 유착된 과거를 청산하고 히어로의 독립성을 되찾으려 한다.
- [[LIMEN]]에게는 **반감시 명분**이 선명해진다 — 감시가 강화될수록 미등록 이레귤러의 생존이 어려워지고, 저항
