# 비동기 반응 기간 보장

> 러너 공개 가능 문서. 운영진 내부 메모는 [[플랫폼_이벤트_조사_엔딩_메모]] 5.4 참조.

---

## 목적

비동기 반응 기간은 **실시간 채팅에 없었던 러너도 정해진 기간 안에 공식 행동을 제출할 수 있게 하는 장치**다.

디스코드에서는 사건이 빠르게 흘러간다.  
접속 중인 러너는 바로 대화하고 움직일 수 있지만, 늦게 접속한 러너는 이미 상황이 끝난 것처럼 느끼기 쉽다.

비동기 반응 기간은 이 격차를 줄인다.  
실시간 대화의 속도는 살리고, 공식 결과 확정은 마감 뒤에 진행한다.

---

## 기본 원칙

- 실시간 채팅은 자유롭게 진행한다.
- 공식 결과에 반영되는 행동은 별도로 제출받는다.
- 제출 마감 전까지는 결과를 확정하지 않는다.
- 운영진은 마감 뒤 행동을 모아 정산한다.
- 도시 상태, 감시도, 보상, 부상, 조사 결과는 웹에 기록한다.
- 실시간 채팅에 참여하지 못해도 공식 행동 제출 기간 안에 참여하면 정산 대상에 포함한다.

---

## 운영 흐름

```text
1. 사건 공지
2. 실시간 반응 채널 개방
3. 공식 행동 제출 기간 안내
4. 러너 행동 제출
5. 마감
6. 운영진 정산
7. 결과 공지와 웹 기록
```

권장 기본값은 **48시간**이다.  
짧은 소문이나 뉴스는 24시간, 전투 포함 메인 이벤트는 48~72시간이 적합하다.

| 상황 | 권장 기간 | 용도 |
|---|---:|---|
| 짧은 뉴스, 소문 | 24시간 | 감상, 짧은 반응 |
| 일반 조사 이벤트 | 48시간 | 조사, 이동, 공동 행동 |
| 전투 포함 이벤트 | 48~72시간 | 전투 신청, 아이템 사용, 조사 병행 |
| 엔딩 직전 선택 | 72시간 이상 | 최종 선택, 개인 판단 |
| 보상 없는 미니 이벤트 | 12~24시간 | 가벼운 즉흥 반응 |

---

## 실시간 반응과 공식 행동 구분

### 실시간 반응

실시간 반응은 채팅에서 바로 진행하는 대화와 장면이다.

예시:

- 사건 현장에 대한 짧은 반응
- 다른 캐릭터와 대화
- 소문에 대한 감상
- 뉴스 공유
- 가벼운 이동 묘사
- 진영별 의견 교환

실시간 반응은 관계성과 몰입감을 만든다.  
다만 이 행동만으로 도시 상태, 감시도, 전투 결과가 크게 바뀌지는 않는다.

### 공식 행동

공식 행동은 운영 결과에 반영되는 행동이다.

예시:

- 조사 신청
- 전투 참여
- 민간인 구조
- 감시 로그 확인
- 감시 로그 탈취
- 아이템 사용
- 능력 사용
- NPC 접촉
- 증거 확보
- 현장 봉쇄
- 도주 지원

공식 행동은 웹 또는 지정 채널로 제출한다.  
운영진은 제출된 행동을 모아 정산한다.

---

## 디스코드 채널 예시

```text
#이벤트-공지
#이벤트-현장채팅
#이벤트-행동제출
#이벤트-질문
#이벤트-결과
```

현장채팅과 행동제출은 분리한다.  
현장채팅은 빠르게 흘러도 된다.  
행동제출은 마감 전까지 받는다.

포럼형으로 운영할 경우에는 다음처럼 묶을 수 있다.

```text
[이벤트] 잔광 경보
- 공지
- 현장 반응
- PARAGON 행동 제출
- LIMEN 행동 제출
- 공동 행동 모집
- 결과 정리
```

## 러너 공개 공지 예시

```md
본 커뮤니티의 이벤트는 실시간 반응과 공식 행동 제출을 구분합니다.

실시간 반응 채널에서는 자유롭게 대화와 장면 진행이 가능합니다.
다만 도시 상태, 감시도, 아이템, 전투 결과, 조사 결과에 영향을 주는 행동은 지정된 공식 행동 제출을 통해 반영됩니다.

이벤트마다 공식 행동 제출 기간이 안내됩니다.
해당 기간 안에 제출된 행동은 접속 시간과 관계없이 정산 대상에 포함됩니다.

실시간 채팅에 참여하지 못해도 공식 행동 제출 기간 안에 참여하면 이벤트 결과에 반영될 수 있습니다.
```

짧은 버전은 다음과 같다.

```md
이벤트 결과는 실시간 채팅만으로 확정되지 않습니다.
러너는 공지된 제출 기간 안에 공식 행동을 제출할 수 있으며, 운영진은 마감 후 이를 종합해 결과를 공개합니다.
```

## 이벤트 적용 예시: 잔광 경보

### 사건 공지

```md
하층 상가 3번 감지탑에서 잔광 경보가 발생했습니다.
관리감시국은 인근 구역에 이동 제한을 권고했습니다.
PARAGON 현장 대응팀이 출동했고, LIMEN 관련 비인가 접속 흔적이 감지되었습니다.

공식 행동 제출 기간:
5월 21일 21:00 ~ 5월 23일 23:59

결과 공개:
5월 24일 도시 브리핑
```

### PARAGON 행동 선택 예시

```md
- 민간인 대피 지원
- 감지탑 보호
- LIMEN 추적
- 관리감시국 기록 열람 요청
- 부상자 구조
```

### LIMEN 행동 선택 예시

```md
- 감시 로그 탈취
- 차폐 지하로 확보
- 포획 대상 회수
- 감지탑 교란
- 추적 흔적 삭제
```

### 공통 행동 선택 예시

```md
- 현장 조사
- 목격자 보호
- 능력 사용
- 아이템 사용
- 다른 캐릭터와 공동 행동
```

---

## 행동 제출 양식 예시

```md
## 캐릭터명

## 진영
PARAGON / LIMEN / 기타

## 참여 구역
하층 상가 / 감지탑 주변 / 차폐 지하로

## 선택 행동
감시 로그 확인

## 행동 설명
현장에 남은 잔광 패턴과 감지탑 기록 시간을 비교한다.

## 능력 또는 아이템 사용 여부
사용함 / 사용하지 않음

## 감시도 상승 위험 동의
동의 / 비동의

## 공동 행동자
없음 / 캐릭터명 기재
```

행동 설명은 짧아도 된다.  
운영진이 정산할 수 있을 정도의 목적과 방식만 있으면 된다.

---

## 결과 정산 예시

```md
## 잔광 경보 결과

민간인 대피 행동이 많아 시민 피해가 줄었습니다.
뉴 센티넬 안정도 하락 폭이 감소합니다.

PARAGON 측 감지탑 보호가 일부 성공했습니다.
감지탑 본체는 유지되었지만, 일부 로그에는 공백이 생겼습니다.

LIMEN 측 로그 탈취가 일부 성공했습니다.
관리감시국 발표와 실제 현장 기록 사이에 차이가 있다는 단서가 해금됩니다.

공개 장소에서 능력 사용이 확인된 캐릭터는 감시도 변동 대상이 됩니다.
자세한 변동은 웹 개인 상태 페이지에 반영됩니다.
```

결과는 개인별 장문보다 묶음 정산이 적합하다.  
필요한 경우에만 개인 결과를 추가한다.

---

## 운영 주의점

- 마감이 지나면 원칙적으로 공식 결과에 반영하지 않는다.
- 지각 제출은 운영진 판단으로 보조 반응 처리할 수 있다.
- 실시간 참여자에게만 핵심 단서와 큰 보상이 몰리면 안 된다.
- 비동기 참여자도 조사, 보상, 감시도, 이벤트 참여 인정에서 불이익이 없어야 한다.
- 공식 반영 행동은 너무 많게 열지 않는다.
- 선택 행동은 보통 5~8개 정도가 적당하다.
- 모든 결과는 디스코드 채팅이 아니라 웹에 최종 기록한다.

---

## 한 줄 요약

비동기 반응 기간은 **디스코드의 빠른 현장감은 살리고, 늦게 접속한 러너의 공식 참여 기회는 보장하는 운영 규칙**이다.
