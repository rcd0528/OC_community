# 감시도와 여론 시스템

> 이 문서는 개인 단위 감시도와 도시 단위 시민 여론, 두 가지 운영 시스템을 정리한다.
> 감시도는 [[이레귤러 관리감시국]]이 특정 인물을 얼마나 위험하게 보는지, 시민 여론은 뉴 센티넬의 분위기가 어떤 방향으로 흐르는지를 나타낸다.

---

## 1. 감시도

### 1.1 정의

감시도는 [[이레귤러 관리감시국]]이 특정 인물을 얼마나 위험하게 보고 있는지 나타내는 **개인 지표**다. 공명지수, 등급, 감시도는 서로 다르다.

| 항목 | 의미 |
| --- | --- |
| 공명지수 | [[잔명]]에 대한 생체 반응과 능력 안정성 |
| 등급 | 능력 규모, 숙련도, 작전 권한 |
| 감시도 | 관리감시국이 보는 현재 위험도와 주시 수준 |

### 1.2 단계

| 단계 | 명칭 | 상태 | RP 효과 |
| ---: | --- | --- | --- |
| 0 | 일반 기록 | 기본 등록 상태 | 별도 제약 없음 |
| 1 | 관찰 | 최근 능력 사용 기록 있음 | 등록증 알림, 사후 보고 요청 |
| 2 | 주의 | 위험 행동 또는 제한 구역 기록 | 임무 후 소명, 이동 시 알림 |
| 3 | 집중감시 | 반복 위반, 고위험 로그 | 특정 구역 출입 제한, 추적 NPC 등장 |
| 4 | 통제대상 | 폭주·민간 피해·불법 작전 연루 | 체포 영장, 면허 정지, 강제 소환 |
| 5 | 긴급위험 | 도시급 위협 또는 정치적 표적 | 특별 이벤트, 봉쇄·진압 명령 |

감시도 5단계가 자동 퇴장을 뜻하지 않는다. 전용 이벤트, 도주 선택지, 소명 기회, 보호 요청, 폭로 루트로 이어진다.

### 1.3 상승 조건

| 조건 | 상승량 |
| --- | ---: |
| 제한 구역 내 능력 사용 | +1 |
| B등급 이상 제한 구역에서 무허가 전투 | +1 |
| 시민 부상 발생 | +1~2 |
| 민간 시설 대규모 파괴 | +1~2 |
| 감시 로그 조작 시도 | +1 |
| 등록 데이터 탈취 | +1~2 |
| 관리감시국 긴급명령 불복종 | +1 |
| 제어제·증폭제·더스트 관련 연루 | +2 |
| 폭주 발생 또는 폭주자 은닉 | +2 |
| 언론에 위험 인물로 보도 | +1 |
| 누명 또는 로그 조작 피해 | +1, 추후 해소 가능 |

### 1.4 하락 조건

| 조건 | 하락량 |
| --- | ---: |
| 사건 후 자진 보고 | -1 |
| 시민 구조 공적 인정 | -1 |
| 의료 검사와 안정성 확인 | -1 |
| 관리감시국 조사 협조 | -1 |
| 누명 해소 증거 확보 | -1~2 |
| [[PARAGON]] 공식 보증 | -1 |
| 일정 기간 문제 행동 없음 | -1 |
| 로그 조작 진범 확인 | -2 |

### 1.5 LIMEN과 감시도

[[LIMEN]] 캐릭터는 감시도를 정상 경로로 낮추기 어렵다. 대신 **위장, 차폐, 로그 분산**으로 표면 감시도를 낮출 수 있다.

> 실제 감시도 4 / 표면 감시도 2
> 사유: LIMEN 절단자의 로그 위장 성공.
> 단, 다음 감시국 조사 이벤트에서 위장 흔적이 드러날 수 있음.

## 2. 시민 여론

### 2.1 운영 변수

총괄 1인 운영 기준으로 시민 여론은 **4개 변수**만 관리한다.

| 변수 | 의미 | 공개 방식 |
| --- | --- | --- |
| 뉴 센티넬 안정도 | 도시가 안전하다고 느껴지는 정도 | 공개 가능 |
| PARAGON 신뢰도 | 시민이 히어로 조직을 믿는 정도 | 공개 가능 |
| 감시 체계 신뢰도 | 시민이 관리감시국과 등록 제도를 받아들이는 정도 | 공개 가능 |
| LIMEN 영향력 | 시민, 음지, 미등록자 사이에서 LIMEN이 얻는 힘 | 반공개 또는 뉴스 문구 |

`LIMEN 영향력`은 숫자로 공개하지 않는 편이 자연스럽다. 뉴스, 소문, 구도심 반응, 미등록자 네트워크 묘사로 보여준다.

### 2.2 5단계 표현 척도

5단계 여론 척도는 각 변수의 **표현 방식**으로 쓴다.

| 단계 | 표현 |
| --- | --- |
| 1 | 공포 |
| 2 | 불신 |
| 3 | 관망 |
| 4 | 지지 |
| 5 | 열광 또는 의존 |

양끝을 선악으로 처리하지 않는다. 공포는 억압을 강화하고, 열광은 의존과 광신으로 이어질 수 있다.

### 2.3 행동 태그

러너의 예상 밖 선택은 행동 태그로 처리한다. 러너의 행동을 다음 태그 중 하나 이상으로 분류한 뒤 변수 변동에 반영한다.

| 태그 | 의미 |
| --- | --- |
| 구조 | 시민, 피해자, 폭주자, 미등록자를 살림 |
| 피해 | 시민 부상, 시설 파괴, 정전, 교통 마비 |
| 폭로 | 숨겨진 정보를 공개함 |
| 은폐 | 정보를 감추거나 회수함 |
| 통제 | 봉쇄, 체포, 강제 진압, 제어제 사용 |
| 자율 | 현장 판단, 명령 거부, 협상, 탈출 지원 |
| 안정 | [[잔광]] 농도 하락, 인프라 복구 |
| 불신 | 조작 의혹, 사망자 발생, 내부 배신 |

## 3. 진영별 변동 기준

### 3.1 PARAGON 변동

| 행동 | PARAGON 신뢰도 | 감시 체계 신뢰도 | 뉴 센티넬 안정도 |
| --- | ---: | ---: | ---: |
| 시민 피해 없이 구조 성공 | +2 | 0 또는 +1 | +1 |
| LIMEN 저지 성공, 시민 피해 발생 | +1 또는 0 | +1 | 0 |
| 관리감시국 명령을 따르고 빠르게 안정화 | 0 또는 +1 | +2 | +1 |
| 명령을 거부하고 피해자 보호 | +1 또는 -1 | -1 | 0 |
| 내부 비리 공개 | 단기 -1, 후반 +2 | -2 | -1 |
| 제어제·강제진압 사용 | -2 | +1 | +1 |
| 사건 은폐 | 단기 +1, 후반 -3 | +1 | 0 |
| LIMEN과 임시 공조 | -1 또는 +1 | -1 | +1 |

PARAGON은 시민 피해를 줄일수록 신뢰를 얻는다. 감시와 은폐에 기대면 히어로로서의 신뢰가 깎인다.

### 3.2 LIMEN 변동

| 행동 | LIMEN 영향력 | PARAGON 신뢰도 | 감시 체계 신뢰도 |
| --- | ---: | ---: | ---: |
| 미등록자·피해자 구출 성공 | +2 | 0 또는 -1 | -1 |
| 민간 피해 없이 기록 탈취 | +2 | -1 | -1 |
| 관리감시국 비리 증거 공개 | +2 | 사건별 변동 | -2 |
| 시민 피해를 감수한 시설 파괴 | -2 또는 +1 | +1 | +1 |
| 민간인 개인정보 유출 | -3 | 0 | -1 |
| 폭주자 은닉 후 사고 발생 | -3 | +1 | +2 |
| PARAGON 현장팀과 협력해 구조 | +1 | +1 | -1 |
| 더스트·증폭제 사용 | 단기 +1, 후반 -3 | +1 | +1 |

LIMEN은 시민 피해를 줄이고 증거를 정확히 공개할수록 영향력을 얻는다. 무차별 파괴, 개인정보 유출, 증폭제 남용은 명분을 크게 깎는다.

## 4. 운영 참고

- 감시도는 **개인 단위**, 시민 여론은 **도시 단위**다. 서로 독립적이지만 상호 영향을 준다.
- 여론 변수는 이벤트 종료 후 **결과 카드**에 포함하여 공개한다.
- 감시도 변동은 해당 캐릭터에게 개별 통보한다.
- 총괄 1인 운영 기준이므로, 지나치게 세밀한 수치 계산보다 **방향성 판단**을 우선한다.
