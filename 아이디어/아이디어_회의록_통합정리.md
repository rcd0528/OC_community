# 아이디어 회의록 통합본

## 1. 중간 점검 결과

현재 회의록 안에는 치명적인 설정 충돌이 없다.  
다만 실제 문서에 반영하기 전에 정리해야 할 표현 불일치와 우선순위 변경이 있다.

### 정리된 불일치

| 항목 | 이전 표현·후보 | 최종 정리 |
|---|---|---|
| 시리즈 주제 | `선도 악도 없다` | `완전한 선도, 완전한 악도 없다` |
| 진영 구조 | 다극 진영처럼 보이는 표현 | 플레이어블은 PARAGON·LIMEN 2진영, 세계관 압력은 다극 구조 |
| 정부 감시 기관 | 정부 감시국, 연방 이레귤러 감독청, FIRA 등 | `이레귤러 관리감시국`으로 통일 |
| 감시 기관의 위치 | 독립 세력 또는 3진영처럼 보일 수 있음 | 러너 가입 진영이 아닌 환경 장치 |
| 시민 여론 | 5단계 척도와 4개 변수가 섞여 있음 | 4개 운영 변수 + 5단계 표현 척도로 정리 |
| D등급 | D등급 지망생 표현과 신청 불가 정책 공존 | 러너 신청은 C~S, D등급은 NPC·과거 이력만 허용 |
| 플랫폼 | 디스코드·마스토돈 중 택일 고민 | 마스토돈 메인 RP, 자체 사이트 시스템, 디스코드 보조 |
| 감시도 | 후보 시스템 | 개인 단위 0~5단계 시스템으로 승격 검토 |

## 2. 중심 주제

시리즈를 관통하는 주제는 다음 문장으로 고정한다.

> 완전한 선도, 완전한 악도 없다.

이 문장은 모든 진영을 같은 수준으로 흐리게 만들기 위한 문장이 아니다.  
각 진영이 실제로 옳은 일을 할 수 있고, 동시에 잘못된 선택도 할 수 있다는 기준이다.

PARAGON은 시민을 구한다.  
LIMEN은 불법을 저지르면서도 누군가를 보호할 수 있다.  
이레귤러 관리감시국은 사고를 줄이지만 사람을 통제한다.  
시민 여론은 피해자의 편에 서기도 하고, 공포 때문에 억압을 지지하기도 한다.

러너가 오래 기억하는 장면은 선악 구호보다 선택의 대가에서 나온다.  
이 세계관은 러너에게 “이겼는가”보다 “무엇을 잃고 무엇을 지켰는가”를 묻는다.

## 3. 운영 구조 결정사항

### 3.1 플레이어블 진영

플레이어블 진영은 두 개로 고정한다.

| 진영 | 플레이 감각 | 주요 행동 |
|---|---|---|
| PARAGON | 지키는 재미 | 구조, 방어, 체포, 질서 유지, 내부 고발, 명령 거부 |
| LIMEN | 뚫는 재미 | 침투, 탈취, 구출, 폭로, 도주, 기록 조작, 은신 지원 |

3진영 운영은 총괄 1인 기준으로 부담이 크다.  
이레귤러 관리감시국은 플레이어블 진영으로 열지 않는다.

### 3.2 세계관 압력

세계관은 2진영만으로 굴러가지 않는다.  
뉴 센티넬의 힘은 다음 요소들이 함께 만든다.

- 이레귤러 관리감시국
- 시민 여론
- 언론
- 시민 권리 운동 단체
- 민간기업
- 보험사와 병원
- 오러라이트 산업계
- 미등록 이레귤러 지원망

정리 문장:

> 공개 러닝 진영은 PARAGON과 LIMEN 두 개다.  
> 세계관의 압력은 이레귤러 관리감시국, 시민 여론, 권익단체, 언론, 민간기업이 함께 만든다.

## 4. 이레귤러 관리감시국

### 4.1 명칭

공식 명칭은 `USNA 이레귤러 관리감시국`으로 정한다.

| 용도 | 표기 |
|---|---|
| 공식 기관명 | USNA 이레귤러 관리감시국 |
| 공개 문서 약칭 | 관리감시국 |
| 시민·언론 약칭 | 감시국 |
| LIMEN·반등록 은어 | 감시국, 목줄, 등록망 |
| 시스템 UI | `[이레귤러 관리감시국]` |

`연방 이레귤러 감독청`, `FIRA`, `FIB`, `ISA`, `BIR` 등의 후보는 이번 정리본에서 폐기한다.  
기존 문서 안에 남은 해당 표현은 `이레귤러 관리감시국`으로 교체한다.

### 4.2 역할

이레귤러 관리감시국은 제3진영이 아니다.  
도시의 법, 기록, 출입 통제, 현장 봉쇄, 사후 브리핑으로 작동하는 환경 장치다.

| 장치 | 러너가 체감하는 방식 |
|---|---|
| 긴급명령 | 특정 구역에서 능력 사용 제한, 출동 명령, 대피 명령 |
| 출입 통제 | 허가증 요구, 제한 구역 진입 시 감시도 상승 |
| 감시 로그 | 능력 사용, 폭주, 시민 피해, 로그 조작 기록 |
| 사후 보고 | 전투 후 사건 책임과 공적을 공식 발표 |
| 언론 브리핑 | 시민 여론을 특정 방향으로 유도 |
| 현장 봉쇄 | 이동 경로 제한, 우회 루트 요구 |
| 등록증 알림 | 개인 단위 경고, 소명 요청, 조사 통보 |
| 사법 리스크 | 체포, 소환, 면허 정지, 임무 제한의 근거 |

### 4.3 환경 장치로 쓰는 이유

관리감시국을 직접 상대하는 보스나 가입 진영으로 만들면 운영량이 급격히 늘어난다.  
반대로 환경 장치로 두면 모든 이벤트에 압력을 줄 수 있다.

전투 이벤트에서 관리감시국은 다음 방식으로 등장한다.

| 시점 | 장치 | 효과 |
|---|---|---|
| 이벤트 시작 | 긴급 봉쇄령 | 구역 이동 제한, 우회 루트 필요 |
| 1페이즈 | 능력 사용 제한 | 고등급 능력 사용 시 감시도 상승 |
| 2페이즈 | 자동 로그 업로드 | 일정 턴 후 현장 기록이 서버로 전송 |
| 3페이즈 | 진압 드론 투입 | 시민 피해가 커지면 양 진영 모두 방해 |
| 종료 후 | 공식 브리핑 | 여론, 감시도, 도시 안정도 변동 |

러너는 관리감시국과 매번 직접 싸우지 않는다.  
관리감시국이 만든 규칙 안에서 무엇을 지키고 무엇을 어길지 선택한다.

## 5. 히어로 vs 빌런 구조

이 커뮤니티는 전통적인 히어로 vs 빌런 구도를 사용한다.  
대립은 선명해야 한다. 러너는 자기 진영이 무엇을 해야 하는지 바로 알아야 한다.

### 5.1 이벤트 기본 구조

모든 큰 이벤트는 다음 순서로 설계한다.

1. 표면 목표를 선명하게 제시한다.
2. 중간 정보로 명분을 흔든다.
3. 결과를 다음 챕터에 남긴다.

### 5.2 표면 목표 예시

| PARAGON | LIMEN |
|---|---|
| 시설을 지켜라 | 기록을 탈취하라 |
| 폭주자를 진압하라 | 폭주자를 빼내라 |
| 시민을 대피시켜라 | 봉쇄망을 뚫어라 |
| 로그 코어를 회수하라 | 로그 코어를 파괴하라 |
| 관리감시국 명령을 수행하라 | 관리감시국 기록을 끊어라 |

### 5.3 명분을 흔드는 정보 예시

- 폭주자는 증폭제 사용자가 아니라 제어제 부작용 피해자였다.
- LIMEN이 훔치려던 데이터에는 민간인 개인정보도 들어 있다.
- PARAGON이 지키는 병원 지하에 비공개 격리실이 있다.
- 관리감시국의 봉쇄령은 시민 보호에도 필요하지만, 증거 보존에는 불리하다.
- 구조 대상 시민이 과거 이레귤러 폭행 사건의 가해자다.

### 5.4 후폭풍 예시

- PARAGON이 시민을 구했지만 강제 진압 영상이 퍼져 신뢰도가 떨어진다.
- LIMEN이 기록을 폭로했지만 유출된 명단 때문에 미등록자 사냥이 시작된다.
- 양 진영이 협력해 폭주자를 살렸지만, 관리감시국은 이를 불법 공모로 규정한다.
- 시민 피해를 줄인 선택 때문에 핵심 증거가 사라진다.
- 진실을 공개한 선택 때문에 도시 안정도가 내려간다.

## 6. 시민 여론 시스템

### 6.1 운영 변수

총괄 1인 운영 기준으로 시민 여론은 4개 변수만 관리한다.

| 변수 | 의미 | 공개 방식 |
|---|---|---|
| 뉴 센티넬 안정도 | 도시가 안전하다고 느껴지는 정도 | 공개 가능 |
| PARAGON 신뢰도 | 시민이 히어로 조직을 믿는 정도 | 공개 가능 |
| 감시 체계 신뢰도 | 시민이 관리감시국과 등록 제도를 받아들이는 정도 | 공개 가능 |
| LIMEN 영향력 | 시민, 음지, 미등록자 사이에서 LIMEN이 얻는 힘 | 반공개 또는 뉴스 문구 |

`LIMEN 영향력`은 숫자로 공개하지 않는 편이 자연스럽다.  
뉴스, 소문, 구도심 반응, 미등록자 네트워크 묘사로 보여준다.

### 6.2 5단계 표현 척도

5단계 여론 척도는 각 변수의 표현 방식으로 쓴다.

| 단계 | 표현 |
|---|---|
| 1 | 공포 |
| 2 | 불신 |
| 3 | 관망 |
| 4 | 지지 |
| 5 | 열광 또는 의존 |

양끝을 선악으로 처리하지 않는다.  
공포는 억압을 강화하고, 열광은 의존과 광신으로 이어질 수 있다.

### 6.3 행동 태그

예상 밖의 선택은 행동 태그로 처리한다.  
러너의 행동을 다음 태그 중 하나 이상으로 분류한 뒤 변수 변동에 반영한다.

| 태그 | 의미 |
|---|---|
| 구조 | 시민, 피해자, 폭주자, 미등록자를 살림 |
| 피해 | 시민 부상, 시설 파괴, 정전, 교통 마비 |
| 폭로 | 숨겨진 정보를 공개함 |
| 은폐 | 정보를 감추거나 회수함 |
| 통제 | 봉쇄, 체포, 강제 진압, 제어제 사용 |
| 자율 | 현장 판단, 명령 거부, 협상, 탈출 지원 |
| 안정 | 잔광 농도 하락, 인프라 복구 |
| 불신 | 조작 의혹, 사망자 발생, 내부 배신 |

예시:

- PARAGON이 LIMEN과 협상해 폭주자를 살렸다.  
  태그: 구조 + 자율 + 불신
- LIMEN이 서버를 파괴해 미등록자 명단을 지웠다.  
  태그: 자율 + 은폐 + 피해
- PARAGON이 명령대로 구역을 봉쇄했다.  
  태그: 통제 + 안정
- LIMEN이 기록을 폭로했지만 민간인 개인정보까지 유출됐다.  
  태그: 폭로 + 피해 + 불신

### 6.4 PARAGON 변동 기준

| 행동 | PARAGON 신뢰도 | 감시 체계 신뢰도 | 뉴 센티넬 안정도 |
|---|---:|---:|---:|
| 시민 피해 없이 구조 성공 | +2 | 0 또는 +1 | +1 |
| LIMEN 저지 성공, 시민 피해 발생 | +1 또는 0 | +1 | 0 |
| 관리감시국 명령을 따르고 빠르게 안정화 | 0 또는 +1 | +2 | +1 |
| 명령을 거부하고 피해자 보호 | +1 또는 -1 | -1 | 0 |
| 내부 비리 공개 | 단기 -1, 후반 +2 | -2 | -1 |
| 제어제·강제진압 사용 | -2 | +1 | +1 |
| 사건 은폐 | 단기 +1, 후반 -3 | +1 | 0 |
| LIMEN과 임시 공조 | -1 또는 +1 | -1 | +1 |

PARAGON은 시민 피해를 줄일수록 신뢰를 얻는다.  
감시와 은폐에 기대면 히어로로서의 신뢰가 깎인다.

### 6.5 LIMEN 변동 기준

| 행동 | LIMEN 영향력 | PARAGON 신뢰도 | 감시 체계 신뢰도 |
|---|---:|---:|---:|
| 미등록자·피해자 구출 성공 | +2 | 0 또는 -1 | -1 |
| 민간 피해 없이 기록 탈취 | +2 | -1 | -1 |
| 관리감시국 비리 증거 공개 | +2 | 사건별 변동 | -2 |
| 시민 피해를 감수한 시설 파괴 | -2 또는 +1 | +1 | +1 |
| 민간인 개인정보 유출 | -3 | 0 | -1 |
| 폭주자 은닉 후 사고 발생 | -3 | +1 | +2 |
| PARAGON 현장팀과 협력해 구조 | +1 | +1 | -1 |
| 더스트·증폭제 사용 | 단기 +1, 후반 -3 | +1 | +1 |

LIMEN은 시민 피해를 줄이고 증거를 정확히 공개할수록 영향력을 얻는다.  
무차별 파괴, 개인정보 유출, 증폭제 남용은 명분을 크게 깎는다.

## 7. 감시도 시스템

### 7.1 정의

감시도는 이레귤러 관리감시국이 특정 인물을 얼마나 위험하게 보고 있는지 나타내는 개인 지표다.  
공명지수, 등급, 감시도는 서로 다르다.

| 항목 | 의미 |
|---|---|
| 공명지수 | 잔명에 대한 생체 반응과 능력 안정성 |
| 등급 | 능력 규모, 숙련도, 작전 권한 |
| 감시도 | 관리감시국이 보는 현재 위험도와 주시 수준 |

### 7.2 단계

| 단계 | 명칭 | 상태 | RP 효과 |
|---:|---|---|---|
| 0 | 일반 기록 | 기본 등록 상태 | 별도 제약 없음 |
| 1 | 관찰 | 최근 능력 사용 기록 있음 | 등록증 알림, 사후 보고 요청 |
| 2 | 주의 | 위험 행동 또는 제한 구역 기록 | 임무 후 소명, 이동 시 알림 |
| 3 | 집중감시 | 반복 위반, 고위험 로그 | 특정 구역 출입 제한, 추적 NPC 등장 |
| 4 | 통제대상 | 폭주·민간 피해·불법 작전 연루 | 체포 영장, 면허 정지, 강제 소환 |
| 5 | 긴급위험 | 도시급 위협 또는 정치적 표적 | 특별 이벤트, 봉쇄·진압 명령 |

감시도 5단계가 자동 퇴장을 뜻하지 않는다.  
전용 이벤트, 도주 선택지, 소명 기회, 보호 요청, 폭로 루트로 이어진다.

## 8. 등급제

### 8.1 신청 정책

| 등급 | 신청 여부 | 사용 방식 |
|---|---|---|
| D | 신청 불가 | NPC, 과거 이력, 훈련생 배경 |
| C | 신청 가능 | 신참, 현장 입문자, D에서 갓 승급한 인물 |
| B | 신청 가능 | 주력 현장 인력 |
| A | 신청 가능 | 고위험 고성능 전력, 감시 부담 증가 |
| S | 소수 합격 | 도시급 변수, 1~2명 수준 제한 권장 |

D등급은 1기 기준을 따라 신청 불가로 유지한다.  
`D에서 갓 C로 승급한 신참` 설정은 허용한다.

### 8.2 적용 방향

등급은 전투력 순위표로 쓰지 않는다.  
등급은 능력 규모, 통제 안정성, 사회적 위험도, 작전 권한을 함께 나타내는 표식이다.

| 등급 | 가능한 행동 규모 |
|---|---|
| C | 개인 단위 전투, 소규모 구조, 근거리 보조 |
| B | 다수 상대, 구역 일부 방어, 작전 중심 수행 |
| A | 대형 위협 대응, 다중 구조, 위험 구역 진입 |
| S | 재난급 대응, 도시 인프라에 영향, 제한적 출동 |

### 8.3 감시 리스크

고등급일수록 능력 사용 흔적이 강하게 남는다.

| 등급 | 감시 리스크 |
|---|---|
| C | 흔적이 작아 잠입과 은밀 행동에 유리 |
| B | 표준 전투와 구조에 안정적 |
| A | 능력 사용 시 감시 로그가 강하게 남음 |
| S | 출동 자체가 관리감시국 이벤트가 됨 |

이 구조를 쓰면 C/B 캐릭터도 충분히 활약한다.  
고등급은 강하지만, 감시와 정치적 부담이 따른다.

### 8.4 진영별 체감

PARAGON에게 등급은 직위, 임무 배정, 시민 신뢰와 연결된다.

- C등급: 현장 신입, 보조 출동, 증명 욕구
- B등급: 주력 현장 요원
- A등급: 특수 임무, 관리감시국 보고 의무 강화
- S등급: 출동 승인 자체가 정치적 결정

LIMEN에게 등급은 보호 부담과 추적 위험을 뜻한다.

- C등급 미등록자: 감시망을 피해 살 수 있는 현실적 도피자
- B등급 미등록자: 보호 네트워크가 필요한 주요 인물
- A등급 미등록자: 숨겨주는 사람까지 위험해지는 존재
- S등급 미등록자: LIMEN 내부에서도 보호, 이용, 배제 의견이 갈림

## 12. 예시 이벤트: CH.1 정류 노드 봉쇄전

### 12.1 사건 개요

구도심과 센트럴 라이프라인을 잇는 지하 정류 노드에서 잔광 농도가 급상승한다.  
관리감시국은 폭주 사고 가능성을 이유로 해당 구역을 봉쇄한다.  
LIMEN은 노드 안에 갇힌 미등록 이레귤러를 빼내려 한다.  
PARAGON은 시민 대피와 노드 안정화를 명령받는다.

### 12.2 진영 목표

| PARAGON | LIMEN |
|---|---|
| 노드 안정화 | 보호 대상 구출 |
| 시민 구조 | 감시 로그 코어 탈취 |
| LIMEN 저지 | 봉쇄망 돌파 |
| 로그 코어 회수 | 관리감시국 은폐 증거 확보 |

### 12.3 실제 쟁점

- 관리감시국은 노드 안의 기록이 외부로 나가는 것을 막고 싶다.
- 노드 안의 미등록 이레귤러는 폭주자가 아니라 실험 피해자일 수 있다.
- 노드를 강제로 안정화하면 시민 피해는 줄지만 내부 기록 일부가 삭제된다.
- 노드를 끄면 기록은 확보되지만 도시 일부가 정전되고 대피가 늦어진다.

### 12.4 전투 오브젝트

| 오브젝트 | 효과 |
|---|---|
| 시민 대피로 | 확보하면 시민 피해 감소 |
| 정류 노드 제어판 | 안정도 회복 또는 감시망 차단 |
| 로그 코어 | 조사 단서 확보 |
| 차폐 구역 | 폭주자 보호 또는 은닉 |
| 봉쇄 드론 | 방치하면 감시도 상승 |

### 12.5 조사 단서

| 단서 | 획득 조건 |
|---|---|
| 노드 폭주는 자연 사고가 아니다 | 기본 단서 |
| 폭주 직전 관리감시국 서버 접속 기록이 있다 | 조사 성공 |
| 접속자는 PARAGON 계정으로 위장했다 | 고난도 조사 |
| 노드 안 미등록자는 과거 Null-Proto 관련 피해자다 | 위험 단서 |
| 기록 일부는 스카이룸 아카이브 파편과 연결된다 | 후반 공개 단서 |

### 12.6 결과 카드 예시

> **CH.1 결과**  
> 시민 피해: 경상 12명, 사망 없음  
> 정류 노드: 부분 안정화  
> 로그 코어: 일부 파손, 일부 탈취  
> 관리감시국 발표: LIMEN의 테러 가능성 조사 중  
> 비공개 후폭풍: 삭제된 로그 일부가 PARAGON 내부 계정과 연결됨  
> 여론 변동: 뉴 센티넬 안정도 +1 / PARAGON 신뢰도 +1 / 감시 체계 신뢰도 -1 / LIMEN 영향력 +1

## 13. USNA와 안전 관리법

USNA 정치 변동과 이레귤러 안전 관리법은 관리감시국의 법적 근거가 된다.  
뉴 센티넬 구역 설계와 함께 잡는 편이 좋다.

### 13.1 정치 변동

스카이룸 결전 이후 정권 교체가 있었다.  
현 행정부는 안전 우선주의와 감시 강화를 내세운다.  
이 변화는 PARAGON 청산파의 동기와 LIMEN의 반감시 명분을 선명하게 만든다.

### 13.2 이레귤러 안전 관리법 골격

| 조항 | 내용 |
|---|---|
| 등록 의무 조항 | 18세 또는 능력 발현 시 등록 의무 |
| 면허 조항 | 공명지수 측정, 등급별 면허 발급 |
| 거주·이동 제한 조항 | A~S등급 대상 제한 구역 관리 |
| 고용 우선 조항 | 정부, PARAGON, 인가 기업 중심 고용 |
| 응급 동원 조항 | 재난 시 등록 이레귤러 의무 응답 |

이 법은 러너 설정에 바로 쓸 수 있다.  
예시: 면허 정지 전력, 응급 동원 거부, 제한 구역 거주, 미등록 상태, PARAGON 보증인 설정.

## 14. 시민 권리 운동 단체

시민 권리 운동 단체는 여론 시스템의 기반이 된다.  
플레이어블 진영으로 열지 않고, 사건 해석과 뉴스 반응을 만들어주는 외부 세력으로 쓴다.

| 단체 | 성격 | 연결점 |
|---|---|---|
| 공명연대 | 합법 권익단체, 등록 이레귤러 중심 | PARAGON 청산파, 피해자 가족, 법 개정 운동 |

## 16. 수인 only 여부

아직 미결정이다.  
현재 세계관 문서에는 인간과 수인이 모두 존재하는 구조가 남아 있다.  
수인 전용으로 갈 경우 관련 표현을 전체 수정해야 한다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| 수인 only 유지 | 커뮤니티 정체성이 선명함 | 모집 풀이 좁아질 수 있음 |
| ALL종족 허용 | 모집 풀이 넓어짐 | 수인 커뮤니티 색이 약해질 수 있음 |
| 수인 중심 + 인간 소수 허용 | 정체성과 확장성을 같이 잡음 | 신청 기준을 섬세하게 써야 함 |

현재 추천은 `수인 중심 + 인간 허용`이다.  
다만 실제 모집 전략, 지인제 범위, 예상 러너 수에 따라 최종 결정한다.
