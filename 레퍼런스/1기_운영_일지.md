# 1기 운영 일지 (위법인류 :: 죄의 정원)

> **이 문서는 운영진 전용 참조 자료다.**
> 1기(2024년 12월)에서 실제로 진행된 운영 흐름과 시스템을 정리한 자료이며,
> 2기 본 설정 문서가 아니다. 2기 작업의 연속성 유지와 자산 재활용을 위한 참조용으로 사용한다.

---

## 0. 문서 안내

### 무엇인가

이 문서는 1기 운영 일지의 핵심을 정제한 자료다. 14일짜리 실 운영 스크립트를 분석하여, 2기 작업 시 참조 가능한 형태로 정리했다.

### 왜 보관하는가

- 1기와 2기는 같은 세계관을 공유하지만, **2기에서 설정이 상당히 변경**됐다 (REVOKE → LIMEN, 진영 블라인드 불가능 등)
- 그럼에도 **버리기 아까운 운영 노하우와 연출 자산**이 많다
- 2기 작업 시 *"1기에서는 이걸 어떻게 했지?"* 질문에 빠르게 답하기 위한 인덱스 역할

### 2기와의 관계

1기 자산은 2기에서 다음 세 가지 방식으로 활용된다.

| 구분 | 설명 | 예시 |
| --- | --- | --- |
| 직접 활용 | 2기에 그대로 가져와도 무리 없음 | 약식 전투, 본부 조사 운영 표준, BGM 운영 |
| 변형 활용 | 2기 설정에 맞게 조정 후 활용 | 진영 블라인드 → 정체 추적, 점령전 → 화이트 아카이브 잠입 |
| 폐기 또는 보류 | 2기와 정합성이 맞지 않음 | 진영 블라인드제 자체, 진영 색출 투표 |

자세한 분류는 [[#7. 1기 자산 분류표]] 참조.

## 1. 1기 개요

### 기본 정보

- **명칭:** 違法人類 :: 죄의 정원
- **진행 기간:** 2024년 12월 6일 ~ 12월 22일 (16일)
- **플랫폼:** 마스토돈 메인 + 디스코드 보조 + 카카오톡 익명 게시판
- **장르:** BL / 수위프리 (4444) / 수인 only / 어반 판타지 / 히어로 빌런 대립 / 진영 블라인드
- **운영진:** 총괄 + MPC 지원진 (2~3명)

## 2. 일정 흐름 (챕터별)

### 챕터 1 — 일상·진영 블라인드 기간 (D1~D2)

**D1 (12월 6일 22시) — 인트로**

스카이룸 종전 10주년 국제 회담장이 배경. PARAGON이 이능력 제어 앰플을 공개할 예정이며, REVOKE가 이를 탈취하기 위해 잠입. 모든 캐릭터는 신분을 위장한 상태로 회담장에 잠입.

> *"누가 적이고 누가 아군인가. 이제 그 누구도 믿을 수 없게 되었습니다."*

**D2 (12월 8일 21시) — 물약 게임 〈사이드 이펙트〉**

PARAGON 보안 요원이 회담장 안전 명목으로 강제 주사하는 프로토타입 앰플의 부작용 게임. 자유 참여, 12시간 지속. 수위 효과 옵션 별도 표기.

→ **자세한 시스템:** [[#3.3 사이드 이펙트 (물약 게임)]]

### 챕터 2 — 진영 색출 기간 (D3~D5)

**D3 (12월 9일 21시) — 진영 색출 이벤트 〈독 안에 든 쥐〉**

회담장 문이 닫히고 본부 로비로 이동. 상부 지령 "제한 시간 72시간, 이능력 제어 앰플 확보". 진영 색출 기간 개시 (3일).

색출 방법:
- 단서 1대1 교환 (총괄계 포함 DM)
- 약식 전투 진행 → 승자는 단서 획득

익명 게시판 **센티넬 링크** 개설 (18~22시).

**D4 (12월 10일 22시) — 진영 색출 투표**

투표 결과 상위 1~3위 색출. 색출된 인물은 특별 감시 대상. 과반수가 빌런이면 PARAGON 챕터 승리, 반대면 REVOKE 승리.

**D5 (12월 11일 22시) — 진영 색출 기간 종료**

### 리뉴얼 기간 (D6~D7)

**D6 (12월 12일 00시)** — 리뉴얼 기간 시작. 메인 트윗·개인 로그·퍼블릭 트윗 금지.

**D7 (12월 13일 22시) — 리뉴얼 종료 + 시리어스 인트로 + 진영 공개**

스카이룸 폭발 → REVOKE 테러 보도 → 모든 출구 봉쇄 → 7일의 생존전 시작. 모든 캐릭터의 진영 일괄 공개.

> *"우리는 이제 영웅도, 악당도 아닌, 그저 살아남기 위해 엄니를 드러낸 짐승일 뿐입니다."*

### 챕터 3 — 시리어스 기간 (D8~D10)

**D8~D10** — 1:1 전투 이벤트 **ZERO SUM GAME** 진행

- 마스토돈에서 전투 타래, 디스코드 공개 스레드에서 다이스 판정
- 매일 자정 체력·정신력 각 20씩 자동 회복
- 승리 시 상대 소지품 1개 강탈
- 치명상 12시간 방치 시 사망
- 모든 1대1 결과 합산하여 승리 진영에 2크레딧 + 생명 복구제

**병행 진행: PARAGON 본부 조사 3구역**

| 일자 | 구역 | 목적 |
| --- | --- | --- |
| D8 | A 구역 (연구 구역) | 앰플 정보 확보 |
| D9 | B 구역 (통제 구역) | 비공식 실험 흔적 |
| D10 | C 구역 (전술 작전 구역) | 장비 획득 |

→ **자세한 운영 표준:** [[#3.5 본부 조사 시스템]]

### 챕터 4 — 엔딩 분기점 (D11~D14)

**D11~D13 — 점령전 〈ALL OR NOTHING〉**

3일에 걸쳐 6팀(양 진영 3팀씩, 4인 1팀) 토너먼트.

→ **자세한 시스템:** [[#3.6 점령전 (단체 전투)]]

**D14 (12월 20일 21시) — 진영 승패 발표 + 배신 선택**

승리 진영 발표 후, 패배 진영 캐릭터는 **잔류 vs 배신** 선택 (22시까지).

배신 시 멘트:
```
[PARAGON → LIMEN] [캐릭터명], 정의의 가면을 벗어던지고 어두운 심연 속으로 스스로의 발걸음을 내딛습니다.
[LIMEN → PARAGON] [캐릭터명], 어둠 속에서 키워온 증오와 복수심을 내려놓고 정의의 길로 귀환합니다.
```

### 챕터 5 — 엔딩 (D15~D16)

**D15 (12월 21일 21시) — 사망자 처형 RP**

배신자가 자기 동료를 처형하는 연출. 7가지 처형 멘트 풀 사용.

→ **자세한 멘트 풀:** [[#5.4 사망자 처형 연출]]

**D16 (12월 22일 00시) — 승리 진영 분기 선택**

승리 진영 캐릭터가 패배 진영 캐릭터에게 생명 복구제를 사용할지 선택 (양측 합의 시):

1. **숙청 엔딩** — 패배 측 소생, 사용자는 배신자로 숙청
2. **이능력 말소 엔딩** — 양쪽 모두 능력 영구 말소, 일반인 도망자로 살아감

**D16 (12월 22일 21시) — 스토리 엔딩 + 5년 후 후일담**

채택된 엔딩: **엔딩 1 - PARAGON 승리 (Hollow)**

→ **결말 상세:** [[#4. 1기 결말]]

## 3. 사용된 시스템

### 3.1 진영 블라인드제

**개념:** 1기 핵심 메커닉. 일상·색출 기간 동안 모든 캐릭터의 소속 진영이 비공개. 신분을 위장한 채 임무 수행, 진영 공개 시점까지 정체를 들키지 않는 것이 목표.

**작동:**
- 일상 기간 (D1~D2): 모든 캐릭터가 회담 참석자로 위장
- 색출 기간 (D3~D5): 단서 수집을 통한 추리 + 투표로 색출
- 진영 공개 (D7): 별도 폼을 통해 일괄 공개

**2기 호환성: ✗ 폐기**

2기는 스카이룸 결전 5년 후 시점이라 진영이 이미 공개된 세계관. 또한 LIMEN은 느슨한 네트워크라 정체가 명확하지 않다는 설정 자체로 긴장감이 형성됨. 진영 블라인드 강제 시스템은 2기와 정합성이 맞지 않음.

다만 **"센티넬 링크" (익명 게시판) 메커닉은 변형 활용 가능** — 정체를 숨긴 채 정보를 흘리거나 받는 익명 채널.

### 3.2 약식 전투

**개념:** 진영 색출 기간 단서 교환용 미니게임. 본격 전투보다 훨씬 가벼움.

**규칙:**
- 캐릭터 스탯 3개(공격/방어/민첩) 중 하나 선택
- 3라운드 진행, 2승 이상이 승리
- 한 번 쓴 스탯은 재사용 불가
- 메타적 시스템이지만 캐입상 실제 전투처럼 묘사
- 승자: 단서 1개 획득 / 패자: 체력·정신력 10씩 감소

**예시:**
```
캐릭터 A : 공 5 / 방 2 / 민 3
캐릭터 B : 공 3 / 방 3 / 민 4

1라운드 : A공 vs B방 → 5 > 3 → A 승
2라운드 : A방 vs B민 → 2 < 3 → B 승
3라운드 : A민 vs B공 → 3 < 4 → B 승

최종: B 2승 (승리)
```

**2기 호환성: ◎ 직접 활용**

운영 메모의 1대1 전투 시스템 중 **가장 가벼운 옵션**으로 그대로 채택 가능. 운영자 부담이 매우 낮음.

### 3.3 사이드 이펙트 (물약 게임)

**개념:** PARAGON이 회담장 보안 명목으로 강제 주사하는 프로토타입 앰플의 랜덤 부작용 이벤트.

**규칙:**
- 자유 참여, 12시간 지속
- 총괄 계정에 "몸에 이상이 없는지" 확인 요청
- 운영자가 랜덤 효과 배정 (타인과 중복 가능)
- 수위 효과 선호도 별도 표기: `*수위x` / `*전부`
- 미참여 시 부작용 없음 처리

**부작용 유형 예시 (1기 자료):**
- 감정 조절 이상
- 갑작스러운 신체 반응 부조화
- 감각 왜곡, 돌발 행동

**2기 호환성: ◎ 직접 활용**

운영 메모의 **"일상 RP 촉발 장치"** 가장 강력한 형태. 잔광 노출, 더스트 흡입, 차폐 시설 사고, 오러라이트 잔향 노출 등 다양한 2기 설정에 메커니즘 그대로 적용 가능.

### 3.4 ZERO SUM GAME (1대1 전투)

**개념:** 시리어스 기간 1대1 전투 이벤트.

**규칙:**
- 마스토돈 타래에서 전투, 디스코드 공개 스레드에서 다이스
- 매일 자정 체력·정신력 각 20씩 자동 회복
- 승리 시 상대 소지품 1개 강탈 (생명 복구제 포함)
- 체력 0 → 치명상 (12시간 방치 시 사망)
- 정신력 0 → 1턴 후 광기 상태 (정신력 10 이상 회복까지)
- 모든 1대1 결과 합산 → 승리 진영에 2크레딧 + 생명 복구제

**2기 호환성: ○ 변형 활용**

기본 구조는 그대로 가져가되, 2기는 "디스코드 메인" 구조라 마스토돈 부분을 디스코드로 이전. **매일 자정 자동 회복**은 1인 운영 친화적이라 그대로 채택 권장.

### 3.5 본부 조사 시스템

**개념:** 챕터 3에서 PARAGON 본부 3구역(연구·통제·전술 작전)을 순차 활성화하여 진행한 조사 이벤트.

**운영 표준:**
- 디스코드 비공개 스레드에서 진행
- 한 캐릭터는 한 번만 참여 가능
- 최소 5인, 선착순 + 랜덤
- 2시간 제한, 미완료 시 빈손 복귀
- 부상 가능성, 묘사는 러너 자율
- 진영 무관 혼합 편성
- 시간대: 20~22시, 22~24시 (하루 2팀)

**2기 호환성: ◎ 직접 활용**

운영 메모의 조사 시스템에 그대로 적용 가능. 특히 **2기 화이트 아카이브 잠입 이벤트**에 이 구조를 쓰면 검증된 방식 그대로 작동.

### 3.6 점령전 (단체 전투)

**개념:** 1기 최종 단체 전투. 4인 1팀의 6팀 토너먼트(양 진영 3팀씩).

**구조:**
- 맵 시트 활용한 그리드 이동
- A~D 시작 지점 선택
- 매 턴 한 칸 이동 + 조사/매복/전진 중 선택
- 인접 칸은 [인기척] 감지 가능
- 같은 칸 마주치면 즉시 전투
- 조사 완료 칸: 1점 / 전투 승리 시: 점령 점수 1.2배

## 4. 1기 결말

### 4.1 채택된 엔딩 — PARAGON 승리 (Hollow)

> *END#1 - Hollow*

1기는 PARAGON 승리로 마무리됐다. 그러나 결말의 톤은 단순한 승리의 환희가 아니라 **공허함**.

**결말 핵심:**
- 정의 실현 (REVOKE 야망 분쇄)
- 그러나 처참한 현장, 상실 더 큼
- 특수 제작 억제 수갑에 묶여 연방 법정 이송
- 강제 능력 소거 + 끊임없는 감시 처분
- 배신자들은 살아남았으나 불신의 족쇄
- 매스컴은 PARAGON 희생이 아닌 **정부의 탁월한 대처**를 칭송
- 순직자는 짧은 명단으로만 처리
- 도시는 일상 회복, 핏자국 지워짐, 깨진 유리 교체 — *"마치 아무 일도 없었던 것처럼"*

**결말 명대사:**
> *"우리가 흘린 피, 그 모든 희생은 과연 정당했을까요?*
> *이 평화는 과연 우리가 바라던 모습일까요?"*

> *"진정한 승리인지, 또 다른 비극의 시작인지, 아무도 알 수 없었습니다.*
> *다만, 우리가 지켜낸 평화는, 그다지 유쾌하지만은 않았습니다."*

### 4.2 결말의 정치적 여파 (2기 직결)

1기 결말은 2기 세계관의 **직접적 전제**가 됨.

| 1기 결말 요소 | 2기 반영 |
| --- | --- |
| 이능력자 안전 관리법 전면 시행 | 2기 감시사회 테마의 기반 |
| 강제 등록 + 실시간 위치 추적 | 관리감시국 권한 확대의 명분 |
| 정부의 탁월한 대처 칭송 | 정권 교체 + 강경파 집권 |
| REVOKE 잔당 분산 | LIMEN으로 재편성 (5년 후) |
| 스카이룸 부분 재건 | 폐쇄층 + 의혹의 무대로 잔존 |
| 배신자의 불신 족쇄 | 2기 시민 여론의 회색지대 |

### 4.3 5년 후 후일담 톤

> *시간은 흘렀지만, 기억은 멈춰 있습니다."*

이 톤은 2기 작업의 기준이 되는 분위기. 모든 2기 문서가 이 정서 위에 서 있다.

### 4.4 폐기된 엔딩 — REVOKE 승리 (Oblivion)

채택되지 않았지만 운영진 참조용으로 보관.

> *END#2 - Oblivion*

- 정의 죽음, PARAGON 몰락
- 스카이룸 잔해가 거대한 묘비

- 정부가 REVOKE와 협상 → 국가 권위 추락

## 8. 다음 작업 제안

이 문서를 작성하면서 도출된 2기 보강 작업 후보. 우선순위 순.

### 우선순위 1 — 운영 메모 v0.3

운영 메모에 1기 자산 직접 활용 항목들을 통합:

- 약식 전투 시스템 추가
- 시리어스 자동 회복 명시
- 공식 멘트 풀 섹션 신설
- BGM 필드 이벤트 템플릿에 추가
- 시간대 패턴 명시

### 우선순위 2 — 점령전 시스템 상세화

화이트 아카이브 잠입 이벤트에 1기 점령전 구조를 변형하여 적용. 별도 시스템 문서로 작성.

### 우선순위 3 — 공식 멘트 풀 별도 문서 (선택)

멘트 풀이 늘어나면 운영 메모에서 분리하여 `운영/공식_멘트_풀.md`로 신설 검토.

### 우선순위 4 — 스카이룸 아카이브 보강

엔딩 1·2 결말 디테일, 특수 제작 억제 수갑 등을 운영진 비공개 떡밥으로 추가.

### 우선순위 5 — PARAGON.md 보강

특수 제작 억제 수갑, 순직자 처리 프로토콜, 연방 법정 이송 등 1기 결말의 디테일 추가.
